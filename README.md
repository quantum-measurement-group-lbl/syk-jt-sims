# syk-jt-sims
Large N many-body numerical simulations for the Sachdev-Ye-Kitaev (SYK) - Jackiw-Teitelboim (JT) gravity holographic correspondence on the LBNL NERSC high performance computer.

This repository is used to compute correlation functions at large N in the SYK model. The code developed here uses the ["dynamite" repository]([url](https://dynamite.readthedocs.io/en/latest/)) as its base. The code is optimized to use multiprocessing across CPUs, in addition to eventual GPU implementation.
